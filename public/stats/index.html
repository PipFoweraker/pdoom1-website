Calculation Methodology

These statistics are calculated using various automated methods and data sources:

Baseline Doom: Not yet measured, and deliberately not estimated here. Baseline doom is a property of the simulation, so only the game can report it. The intended method — aggregating research, news sentiment and forecasting-platform signals — is a plan, not a running pipeline, and until it runs this stays blank rather than carrying a placeholder.
Frontier Labs: Automatically counted from organizations mentioned in our AI Safety Resources section, with manual verification for accuracy.
Strategic Possibilities: Calculated based on game mechanics, decision trees, and combinatorial analysis of game states. Updated with each major game version.

Data Sources

  • Game Repository: Version info, issue tracking, community engagement
  • AI Safety Resources: Organization tracking and frontier lab identification
  • Game Engine: Mechanics analysis for strategic possibility calculations
  • Community Feedback: Player reports and gameplay analytics (future)
