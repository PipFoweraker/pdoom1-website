🔒 What happens to your feedback

Submitting sends this straight to the team's inbox — no account, no extra step, nothing left for you to do. If that send fails we hand you a pre-filled GitHub issue instead, so nothing you wrote is lost. Text filed on GitHub is public; text that reaches the inbox stays private with the team. Any contact detail you add is used only to reply, is never posted publicly, and is never copied into the GitHub fallback. You can submit anonymously.
