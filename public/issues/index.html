🔒 What happens to your feedback

Submitting sends this straight to the team's inbox — no account, no extra step, nothing left for you to do. If that send fails we hand you a pre-filled GitHub issue instead, so nothing you wrote is lost. Text filed on GitHub is public; text that reaches the inbox stays private with the team. Any contact detail you add is used only to reply, is never posted publicly, and is never copied into the GitHub fallback. You can submit anonymously.

Quick feedback

One click, or a sentence — no name, no email, no form to fill in. This is a different route from the form above: your message is written to our own server before anything on this page tells you it arrived, so nothing here says “thanks” until that write has actually finished.

If it cannot reach us it waits in your browser’s own storage and the page keeps retrying; it clears only once we confirm we have it, and you get a receipt code you can quote to have it erased. What we keep, and for how long, is set out on the privacy page.
