Development Rhythm

How irregularly this actually gets built — and what that means for a score you set.

Every number below is read from the release record when you load the page. None of them is typed into it.

This is an alpha. The ladder forks whenever the rules change enough that old scores stop being comparable, and during an alpha that can be any week. Global boards close when it happens. Your local scores never do — the game writes those to your own machine and that file has no network code in it at all, so nothing here can reach them.

Why this page exists

Most projects show you a roadmap. This one has been too erratic for a roadmap to be honest, so it shows you the record instead.

If that looks rough, it is because it is being built. The alternative was a tidier page that told you less. See also what runs on a schedule here, the design decisions behind the game, and the dev blog.
