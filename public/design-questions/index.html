Design questions

These are the things about p(Doom)1 that are not settled. Not a roadmap and not a promise — a list of questions the game is genuinely holding open, with where each currently stands.

Each line below is a one-sentence summary derived from the design backlog. The full text of each is being prepared. Nothing here is a commitment that a question will be answered a particular way, or at all — an open question is exactly that.
