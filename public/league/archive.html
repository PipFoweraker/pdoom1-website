[ANOMALY] Pre-history: everything before ladder epoch L3

The — weeks below were produced before the L2 → L3 ladder fork, which lands with the week beginning Friday 31 July 2026 in Hobart. They are kept and shown deliberately, but they are not results and are not comparable to anything after it.

The cut is a rules change, not a date. L3 removed the action-point pool entirely in favour of an attention economy, and added office lease and lock-in, four-way founder hours, six previously-inert upgrades and a quirk rebalance. A score set under the old rules and a score set under the new ones are not measuring the same game, so ranking them against each other would be meaningless. That is exactly why the ladder version is part of a board's identity: a board is keyed (seed, L3) — the ladder epoch, never the build number.

The first L3 board opens later on that Friday, not at midnight: —. The week is labelled from its own start because a week cannot be half under one set of rules and half under another — but nothing was submittable until the board opened.

What went wrong before it, separately from the rules change: the weekly rollover ran every Sunday at 14:00 UTC on a Monday-to-Sunday week, two days out of phase with the game's own Friday cadence, and it created the week that was ending ten hours later instead of the week that was starting — so each record is labelled one week behind the period it describes. Every one of these weekly files also contains zero entries, because scores never lived in them. Some records still carry v0.4.1 version stamps from the old pygame client; those are left exactly as found, because restamping them would invent a history that did not happen.

From 30 July 2026 the league week runs Friday 00:00 to Thursday 23:59 in Hobart, which is the clock everything on this site is now anchored to.

They are retained for the record, not for competition. Each card lists the specific problems recorded against that week; the full account, with file paths and counts, is in docs/LEAGUE_EPOCH_ANOMALY.md.

[PRESERVED] Real scores the site never showed

— submissions from — players reached the score API and were never published here. They are not lost — they were captured straight off the live API before anything was repaired, so fixing the fault could not destroy the evidence of it.

Why they were invisible: a board is identified by a key, and the key the game sent did not match the key this site looked under. There were two independent mismatches, and either one alone was enough to lose every score. The score API has no validation, so a wrong key does not return an error — it returns a perfectly valid empty board, which looks exactly like nobody having played.

They are shown here and not merged forward. They were set under earlier rules, and carrying them across an epoch would be precisely the lie the ladder split exists to prevent. Pip is contacting the players directly.
